# Culinary Construct Reborn

Unofficial port of [Culinary Construct](https://github.com/TheIllusiveC4/CulinaryConstruct) by C4 to NeoForge 1.21.1.

Build your own sandwiches and food bowls at the Culinary Station. Put bread or a bowl in the first slot and up to five ingredients next to it. The result is one item that combines their food value and effects, and its look shows what's inside.

The mod id (`culinaryconstruct`) and the API are the same as the original, so addons and datapacks keep working.

## Building

```
./gradlew build          # also runs the game tests
./gradlew runClientSmoke # opens a world and the Culinary Station, then quits
```
